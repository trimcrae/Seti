 All observations associated with known sources were processed
for extraction of low-resolution spectrometer data 
( Chapter IX ).
This was also done for any observations above a signal-to-noise
ratio of 25 in the 12 or 25 um band even if they were not associated
with a known source. The path of the source image through the
focal plane was checked for passage over the spectrometer aperture,
and if this was found then the crossing time and scan rate were
inserted into the output source record so that extraction requests
for sources which survived hours-confirmation could be issued.
 
 Weeks-confirmed source sightings for which spectrometer
extraction requests had been issued were processed for index association.
This involved generating a record which associated the name of
the later sightings with that of the earlier one, and which provided
some housekeeping information about the extraction requests.
