Introduction

The second release of some portions of the IRAS data reflects a number of changes, corrections and improvements to the data. This chapter, written in late 1986-early 1987, describes changes to each of the major datasets and records a number of changes to the formats of the data which will be of importance to people using the various products. The history of the releases of the IRAS data is described in Table XII.A.1.
