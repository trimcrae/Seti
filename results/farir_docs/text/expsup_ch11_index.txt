 Introduction

 In any undertaking of the magnitude of the IRAS data reduction,
there are bound to be errors or software design deficiencies,
which were either generic in the processing, discovered too late
in the processing schedule to be fixed for all the observations
or considered minor enough not to warrant fixing. In this chapter,
all those errors which were recognized at the time of publication
of the catalog (November 1984) are listed. It is realized that
this list does not encompass all the actual errors in the catalog.
